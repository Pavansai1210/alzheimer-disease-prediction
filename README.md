# Alzheimer's Disease Prediction

## Project Description

This project is a Python-based machine learning application for predicting Alzheimer's disease stages from medical images.

The project uses image-based datasets organized into different categories and provides a Python application for processing and predicting the corresponding Alzheimer's disease stage.

## Dataset Categories

The dataset is organized into four categories:

* Mild Demented
* Moderate Demented
* Non Demented
* Very Mild Demented

## Technologies Used

* Python
* TensorFlow
* NumPy
* Scikit-learn
* Flask
* Flask-CORS
* Flask-SQLAlchemy
* Flask-Login
* Bcrypt

## Project Files

* `app.py` — Main application file
* `app1.py` — Application-related Python code
* `bot.py` — Python chatbot/application component
* `requirements.txt` — Python dependencies
* Dataset folders — Images organized according to disease categories

## Installation

Install the required Python packages:

```bash
pip install -r requirements.txt
```

The image dataset is organized into separate folders based on Alzheimer's disease categories.

The project includes a TensorFlow-based model retraining process using image data.

## Purpose

The purpose of this project is to apply machine learning and image processing techniques to Alzheimer's disease stage prediction.
